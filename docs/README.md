# PreCTG 프로젝트 문서

이 디렉토리는 PreCTG를 기획·구현·검토하는 팀원을 위한 사람용 기준 문서를 관리합니다. 구현은 아래 명세의 확정된 요구사항을 따라야 하며, 변경된 구현 결정은 해당 문서에 함께 반영합니다.

## 문서 안내

| 문서 | 주요 독자 | 소유하는 내용 |
|---|---|---|
| [제품 명세](product-spec.md) | 전체 팀, 심사 자료 작성자, 개발자 | 대회 맥락, 문제 정의, 팀 역할, 제품 범위, 요구사항과 완료 조건 |
| [데이터 명세](data-spec.md) | 데이터·모델 개발자, 검토자 | AIHub 스키마, 시점 경계, 누수 방지, 합성 데이터 생성·검증 계약 |
| [아키텍처 및 구현 계획](architecture-and-delivery.md) | MVP 개발자 | 기술 스택, 모듈 구조, 단계별 구현, RiskGate 재사용 범위와 검증 전략 |
| [근거 자료 목록](source-register.md) | 전체 팀, 출처 검토자 | 대회·데이터·임상·합성 데이터 근거의 출처와 사용 상태 |

## 문서 우선순위와 갱신 원칙

- 대회 일정·규정과 데이터 스키마는 각 공식 페이지와 주최 측 최신 공지를 우선합니다.
- 제품 범위와 팀 합의는 `product-spec.md`에 기록합니다.
- 데이터 필드, 입력 시점, 라벨, 생성 규칙이 바뀌면 `data-spec.md`를 먼저 갱신합니다.
- 기술 스택, 모듈 경계, 단계별 완료 조건이 바뀌면 `architecture-and-delivery.md`를 갱신합니다.
- 새 외부 자료를 실제 규칙이나 수치에 사용하면 `source-register.md`에 출처와 사용 목적을 추가합니다.
- 확정되지 않은 임상 임계값이나 대회 운영 해석은 코드에 먼저 넣지 않고 문서의 미결정 사항으로 유지합니다.
