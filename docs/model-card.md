# PreCTG 합성 모델 카드

이 문서는 PreCTG MVP의 LightGBM 모델이 무엇을 보여주고 무엇을 입증하지 않는지 설명합니다.

## 모델 개요

- 모델: LightGBM 이진 분류기
- 목적: 데이터 계약, 시간적 누수 차단, 그룹 분할, 저장·불러오기와 단계형 결과 흐름의 기능 확인
- 학습 데이터: 공개 메타데이터 구조를 참고해 로컬에서 생성한 합성 데이터
- 목표: `synthetic_emergency_after_index`
- 목표 버전: `emergency-after-index-v1`
- 기준시점: `early-window-v1`의 20분 초기 CTG 관찰창 종료 시점

모델은 실제 환자 위험을 예측하거나 임상 성능을 추정하기 위한 것이 아니다.

## 입력 특성

모델은 `field-contract-v1`에서 `model_eligible=true`이고 시점이 `PRE_LABOR` 또는 `EARLY_CTG`인 특성만 사용한다.

- 분만 전: 임신 횟수, 출산 횟수, 임신 주수와 추가 일수
- 초기 CTG: 기저 심박수, 기저 변이도, 가속, 조기·후기·가변·지연 감속, 사인파형 코드

식별자, 공식 `Emergency`, `CA`, 출생 이후 결과, 시점 미확정 필드와 합성 생성 메타데이터는 입력에서 차단한다. 초기 CTG는 완전한 20분 관찰창 출처 정보가 있어야 단일 사례 추론에 사용할 수 있다.

## 학습과 재현성

- 같은 산모 그룹이 학습·검증 세트에 동시에 들어가지 않도록 그룹 분할한다.
- 모델 번들에 입력·관찰창·목표 버전, 순서가 있는 특성 목록, 생성기 버전, 시드, 학습 데이터 체크섬과 주요 의존성 버전을 저장한다.
- 저장 전후 단일 사례 확률이 `1e-9` 이내에서 일치해야 한다.
- 화면의 낮음·관찰·높음 신호는 합성 검증 확률의 상대 분위수다. 임상 임계값이 아니다.

## 실패 동작

모델이 없거나 손상됐거나 현재 특성 계약과 맞지 않으면 ML 결과를 `unavailable`로 반환한다. 입력이 부족하면 `insufficient_data`를 반환한다. 규칙 점수를 확률로 대신하지 않으며 정상처럼 보이는 기본값을 생성하지 않는다.

## 제한과 금지 용도

- 합성 데이터의 AUC, 정확도와 확률을 실제 성능으로 인용하지 않는다.
- 진단, 치료, 처치 우선순위나 실제 환자 의사결정에 사용하지 않는다.
- 공식 데이터의 라벨 정의와 시점을 확인하기 전에 공식 `Emergency`를 현재 목표에 매핑하지 않는다.
- 승인된 임상 검토 없이 합성 시연 규칙을 임상 규칙으로 표현하지 않는다.

실제 데이터 사용 시에는 데이터 사전 확인, 목표 재정의, 그룹 키 검증, 결측 분석, 시간적 누수 재검사, 재학습과 별도의 임상·통계 검토가 필요하다.
