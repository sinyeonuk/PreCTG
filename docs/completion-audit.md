# PreCTG 완료 감사와 팀 확인표

이 문서는 `mvp-delivery-plan.md`의 완료 기준을 구현 증거와 대조하고, 자동화할 수 없는 최종 팀 인수를 기록합니다. 확인되지 않은 항목은 완료로 간주하지 않습니다.

## Gate별 감사

| Gate | 상태 | 현재 증거 |
|---|---|---|
| 0 데이터 계약 | 기술 검증 통과 | `field-contract-v1`, `result-contract-v1`, 시점·누수 계약과 설정 일치 테스트 |
| 1 입력·정규화 | 기술 검증 통과 | JSON·CSV·매핑 입력 동등성, 한국어 코드 왕복, 결측·범위·미지원 필드·원본 불변 테스트 |
| 2 합성 데이터 | 기술 검증 통과 | 두 프로필, 고정 시드 체크섬, 50,000건 스키마·논리·중복 0건, 공개 집계 9개 ±1%p, 모든 시나리오 100건 이상 |
| 3 단계 규칙 | 기술 검증 통과 | 정상·고위험·충돌·입력 부족 골든 결과와 임상 모드 비활성 테스트 |
| 4 LightGBM | 기술 검증 통과 | 산모 그룹 분할, 동일 시드 재학습, 저장 전후 동일성, 누수·손상·계약 불일치 차단 |
| 5 통합·CLI | 기술 검증 통과 | 단일 API/CLI 결과 일치, 생성·학습·단일·배치 명령, 모델 없음·잘못된 입력의 안전한 결과 |
| 6 UX·UI | 기술 검증 통과, 키보드·사람 확인 대기 | 3단계 흐름, 네 화면폭, 기본·고위험·결측·모델 없음, JSON 저장, 로컬 글꼴·자산, 콘솔 오류 없음. 네이티브 입력·버튼과 초점 스타일을 사용하며 전체 키보드 여정은 아래에서 확인 |
| 7 시연·인수 | 기술 준비 완료, 사람 확인 대기 | 데모 순서, 4종 캡처, 벤치마크, 실제 데이터 전환 절차 준비 |

Python 3.11.15 새 가상환경에서 의존성을 처음부터 설치하고 `prectg status`와 자동 테스트 46개를 실행했다. 따라서 설치·패키징 증거는 기존 `.venv`에만 의존하지 않는다.

자동 테스트와 브라우저 검증은 구현 동작을 증명하지만 처음 보는 팀원의 이해도와 의료 표현의 오해 가능성을 대신 판단하지 않는다. 아래 두 확인이 끝나기 전에는 프로젝트 목표를 최종 완료로 닫지 않는다.

## 3분 무지원 데모

검증자는 개발자의 사전 설명 없이 README의 실행 명령과 `demo-and-handover.md`의 빠른 데모만 사용한다.

- [ ] 앱을 로컬에서 실행했다.
- [ ] 대표 사례를 선택하고 입력 확인 화면으로 이동했다.
- [ ] 분석을 실행해 통합 신호와 세 단계의 차이를 설명했다.
- [ ] 합성 모델 확률과 입력 완전성이 다른 개념임을 구분했다.
- [ ] 결과 JSON을 저장했다.
- [ ] 같은 필수 흐름을 키보드만으로 완료했고 초점 위치를 확인할 수 있었다.
- [ ] 전체 과정이 3분 이내였다.
- [ ] 막힌 지점, 이해하기 어려운 문구 또는 죽은 조작이 없었다.

기록:

```text
검증자:
검증일:
소요 시간:
사용 사례:
결과: 통과 / 수정 필요
메모:
```

## 비임상용 문구 교차 검토

검토자는 화면, 저장 JSON, README와 발표에 사용할 캡처를 각각 확인한다.

- [ ] 합성 데이터임이 첫 화면과 결과에서 명확하다.
- [ ] 확률과 등급을 실제 발생 확률·진단·치료 권고로 표현하지 않는다.
- [ ] `안전합니다`, `정상입니다`, `응급입니다`, `진단 결과`, `치료 권고`를 사용하지 않는다.
- [ ] 합성 시연 규칙과 승인된 임상 규칙을 혼동하지 않는다.
- [ ] 모델 없음과 입력 부족에서 임의 확률 또는 낮은 위험 신호를 만들지 않는다.

기록:

```text
검토자 1 / 검토일 / 결과:
검토자 2 / 검토일 / 결과:
수정 요청:
```

## 최종 판정

두 기록이 모두 `통과`이고 수정 요청이 반영된 뒤 다음을 확인한다.

- [ ] 현재 커밋에서 전체 자동 검사가 통과한다.
- [ ] `origin/main`에 같은 커밋이 반영돼 있다.
- [ ] 팀원이 사용한 화면과 문구가 현재 구현과 일치한다.

최종 승인 기록:

```text
승인자:
승인일:
커밋:
판정: MVP 구현 완료
```
