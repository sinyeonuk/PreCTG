# PreCTG 프로젝트 전용 에이전트 지침 안내

이 디렉토리는 PreCTG에만 적용되는 에이전트 지침을 안내합니다. 이 README는 사람이 지침 파일의 책임을 찾기 위한 인덱스이며 독립적인 규칙을 정의하지 않습니다.

## 프로젝트 목적

PreCTG는 디버그랩 팀의 「2026 K-Health 미개방 의료데이터 활용 경진대회」 제안서에 삽입할 기능 시연용 MVP입니다. AIHub 「태아 심박동 모니터링 데이터」의 공개 스키마와 합성 테스트 데이터를 사용해 분만 전 EMR 위험도, 초기 CTG 규칙 판정과 LightGBM 기반 응급 관련 위험 추론 흐름을 구현합니다.

현재 MVP는 실제 임상 사용이나 성능 검증을 목적으로 하지 않습니다. 사람용 제품·데이터·아키텍처 명세는 `docs/README.md`에서 안내합니다.
